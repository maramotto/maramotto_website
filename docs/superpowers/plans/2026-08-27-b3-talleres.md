# B-3: Página de talleres — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** construir `/talleres.html` (`/en/workshops.html`) — qué son los talleres, para quién, formato, duración, qué hacen los participantes, y una vía de contacto — para que el nav (`nav.workshops`, ya existente y apuntando hoy a un ancla dentro de una card diminuta) tenga una promesa real detrás.

**Architecture:** página raíz nueva con el mismo patrón de paginación ES/EN que ya usan `index.njk`, `cuerposonoro.njk` y `universo-punzadas.njk` desde B-1 (`pagination.data: languages`, `permalink` condicionado por `lang`, `layouts/base.njk` compartido con nav/footer/head). Contenido en `_data/i18n.js` bajo un namespace `workshops.*` nuevo, siguiendo la voz ya establecida en el resto del sitio (específica, cálida, sin superlativos — ver `brand-review.md` §Summary).

**Tech Stack:** Eleventy 2.0.1 (Nunjucks + paginación), CSS reusando componentes existentes (`.card`, `.btn`, `.tag`), sin dependencias nuevas.

**Spec:** `website-audit.md` §9 Bet 3, F-012; `brand-review.md` B03.

## Global Constraints

- **No fabricar datos concretos** (formato, duración, precio, aforo, ubicación, fotos, testimonios) que este documento no confirme explícitamente. El sitio audit destaca "no placeholder content, no lorem ipsum" como una fortaleza real (F-046) — no la rompas por rellenar huecos con texto genérico.
- **No inventar testimonios.** El brand-review confirma que no existen — igual que en B-5, si no hay cita real, no hay sección de testimonios.
- Reusar componentes CSS existentes (`.card`, `.btn--primary`, `.tag`, `.section-title`) en vez de crear clases nuevas salvo que el layout realmente lo requiera.
- Mantener el flujo de contacto existente (`mailto:hello@maramotto.com`) con `?subject=` propio, igual que ya hacen `cuerposonoro.njk`/`universo-punzadas.njk` con Estratos.
- `npx playwright test` en verde al final; `npm run test:unit` sigue en verde (no se toca ningún filtro de Eleventy en este plan, pero constátalo).
